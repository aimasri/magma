# AI Agent Instructions for Magma

These are the primary rules for any AI assisting with development in this repository.

## Prompt 1: Strict Documentation & Commenting Standards
When creating new code or editing existing code, you MUST maintain the exact same standard of documentation and commenting found in the rest of the application.
- Preserve all existing comments and docstrings that are unrelated to your code changes.
- Add clear, concise comments to any complex logic you introduce.
- Ensure all new functions, classes, and modules have appropriate docstrings matching the project's format.
- Never strip away documentation to save space.
